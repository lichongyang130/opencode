# 专家界面：如何再丰富 · 100 条

针对当前 `/experts`：左侧产品竖栏 + 本周横幅（16:5）+ 领域胶囊 + 圆形头像轨。  
每条尽量可单独开工。示意/规划勿写成已上线能力。

## 一、信息架构与发现（1–12）

1. 横幅下加一行「今日推荐 3 人」，与「全部」分开，避免 15 人同等权重。
2. 领域胶囊旁显示人数（营销 2 · 职场 4），空分类禁用。
3. 增加「最近聊过」轨道，上次专家置顶并标时间。
4. 增加「收藏」星标，收藏轨在全部之前。
5. 搜索不只姓名：技能、示例提问、行业词（PRD、降噪、行程）都能命中。
6. 搜索无结果时给「试试：写文案 / 审代码 / 规划旅行」三个跳转。
7. 用 URL `?id=pm` 打开即选中该专家，方便从对话页回跳。
8. 从 `/chat` 人设选择器加「在专家页查看档案」链过来。
9. 「全部专家」改成可换行网格，窄屏横滑、宽屏 8 列，减少滚走。
10. 领域用图标+字，不只陶土色文字。
11. 增加「场景」筛：上会、求职、出海、家庭，一个专家可进多场景。
12. 首次进入用 3 张引导：点头像换横幅 → 看介绍 → 开始对话。

## 二、本周横幅（13–24）

13. 横幅随选中专家换图，不要多人共用一张脸。
14. 横幅加薄进度条「本周还剩 n 天」，制造周期感（运营配置，勿写死）。
15. 左文右人像固定安全区，避免字压在脸上。
16. 横幅可左右轻滑切专家（与头像轨同步）。
17. 「开始对话」旁加「预览人设」：弹出 system 摘要，不立刻建会话。
18. 横幅底部一条示例提问，点击填入对话输入框（先建会话再填）。
19. 专家有「擅长 / 不接」两行，减少找错人（如法律：不替代律师）。
20. 横幅加语音试听 8 秒（规划），强化人设。
21. 本周专家由运营位配置，不是写死营销策划。
22. 横幅失败（图 404）回退米色底+大 emoji，不要破图。
23. 16:5 在窄屏改 4:5 竖构图，保证人脸。
24. 横幅上加「与 TA 的对话数 / 满意度」示意位，无数据写「新专家」。

## 三、档案与信任（25–36）

25. 点头像不要只换横幅：下方展开 4 段简介（来自现有 system 拆句）。
26. 「示例提问」至少 3 条，按难度：30 秒 / 10 分钟 / 项目。
27. 每条示例带预期产出类型：文案 / PRD / 代码评语 / 行程表。
28. 展示「工作方式」：一次一问、先框架后细节、会追问预算。
29. 展示「禁用项」：编造客户、承诺疗效、编造 ARR。
30. 增加「代表作」三张卡：链到现有文档/PPT 模板（文案专家→手册卡）。
31. 增加「适合谁」：创始人、产品、学生，用小胶囊。
32. 增加「不适合谁」：需要执业签字、需要实时交易。
33. 人设版本号（v3 · 更新于日期），改 prompt 可追溯。
34. 「复制开场白」保留，并加「复制人设说明」给高级用户。
35. 专家页脚统一免责：人设是提示词，不是真人执业。
36. 法律/心理专家档案顶部固定警示条。

## 四、头像轨与人选（37–48）

37. 每人独立肖像，禁止文案/编辑/翻译同一张脸。
38. 选中环用陶土色+姓名下划线，现在只有环不够。
39. 头像下第二行改成「一句话能力」而非只显示领域。
40. 悬停预览：浮层显示示例提问，不必点选。
41. 键盘 ← → 切换专家，Enter 开始对话。
42. 头像轨显示小红点「未读更新」（人设修订）。
43. 允许拖拽排序「我的常用」。
44. 专家超过一屏时，轨左侧渐隐+左右箭头，不要靠用户发现横滑。
45. 当前专家头像轻微放大 1.06，其余降低饱和。
46. 增加「随机一位」骰子，解决选择困难。
47. 按「和我上次任务相近」排序（文档→编辑/PM）。
48. 头像加载用米色骨架圆，避免emoji闪一下。

## 五、对话启动体验（49–60）

49. 开始对话后，聊天顶栏显示专家名、换专家、查看档案。
50. 首条助手消息用该专家开场白，不要空白工作台。
51. 提供「带着当前草稿去问专家」：从 /chat 带输入框内容过来。
52. 同一专家可「新开一场」或「继续上次」。
53. 开始前弹 1 个必填：目标一句话，写入 system 附加上下文。
54. 可选「严格模式」：只输出结构，少寒暄。
55. 可选「教学模式」：多解释为什么（导师类默认开）。
56. 启动失败（建会话失败）留在专家页并 toast 原因。
57. 对话中途换专家：确认是否清空上下文。
58. 专家会话列表用该人头像，不要通用气泡。
59. 支持把专家对话一键「另存为智能体」。
60. 结束对话给 3 个标签：有用 / 跑题 / 太啰嗦，反哺人设。

## 六、内容与专家矩阵（61–72）

61. 现在 15 人偏「职业角色」，补「咨询角色」：董事会预审、路演教练、周报教练（对齐 PPT 卡）。
62. 补「行业专家」：充电桩、茶饮零售、城商行信贷（对齐已有案例，标示意）。
63. 每个领域至少 4 人，避免营销只有 2 个显得空。
64. 专家与技能打通：文档页推荐总编辑，PPT 页推荐路演教练。
65. 专家与模板打通：点「做同款」可勾选专家润色。
66. 允许用户自建专家（名称、emoji、system、示例），进「我的」。
67. 自建专家可从现有人设「另存并改」。
68. 官方专家标「开帆工坊」，自建标「我的」。
69. 专家下架/改名要重定向，旧链接不 404。
70. 多语言专家：英语口语教练默认英，其它默认中，可切换。
71. 「双专家」模式：文案+总编辑接力（规划，先做排队说明）。
72. 专家打包「上会三人组」：PM + 编辑 + 路演，一键顺序问。

## 七、视觉与品牌（73–84）

73. 横幅图按专家配色：技术冷灰、生活暖绿、营销陶土，不要全橙。
74. 头像统一 1:1、面部居中、浅色背景，避免有的大头有的全身。
75. 横幅 16:5 用 CSS 保证，图不够宽时左右渐变垫，不要拉伸脸。
76. 与对话首页米色纸统一，不要专家页突然变杂志黑。
77. 深色模式：横幅更暗、字更亮，头像加细白边。
78. 动效：换专家时横幅淡入 200ms，尊重减少动效。
79. 横幅文字最大宽度 36em，避免中文一行太长。
80. 「开始对话」与头像轨对齐到同一视觉锚（左缘）。
81. 页顶 EXPERTS 英文字可改「本周专家」中文，降低双语噪音。
82. 空状态插画用现有书桌/便签语言，不要 3D 机器人。
83. 打印/分享专家档案：生成一张 16:9 卡片图（姓名+一句话+二维码规划）。
84. 头像轨在 Windows 下显示细滚动条，或始终显示可滑提示。

## 八、运营、数据与商业（85–92）

85. 后台可配置本周专家、横幅文案、下线开关。
86. 记录：曝光、点选、开始对话、首条发送、点赞，做漏斗。
87. 转化差的专家改示例提问，不先改肖像。
88. 会员：部分专家 Pro 锁定，点了出升级条，不假装能聊。
89. 用量：每专家每日演示额度，见顶提示「演示模式」。
90. 专家页 SEO/OG：分享「营销策划顾问」带横幅图。
91. 从落地页 CTA「找专家」深链到 `?id=`.
92. 季度替换 2 名人设，发「专家更新」小条，避免僵尸人设。

## 九、工程、无障碍与风险（93–100）

93. 人设表从 `personas.ts` 抽到可测的纯数据，页面只负责排版。
94. 肖像 map 缺 key 时用颜色+emoji 哈希，禁止 undefined 图。
95. 键盘焦点：胶囊、头像、开始对话可 Tab，焦点环可见。
96. 头像按钮 `aria-pressed`，横幅 `aria-live="polite"` 读出新名字。
97. 法律/医疗口吻过线的 system 加安全前缀（已有心理/法律，检查其它）。
98. 专家名、简介、示例走 i18n，避免硬编码 PITCH 与界面两套文案。
99. 单测：筛选人数、默认选中营销、点头像不跳路由、开始对话才 `push('/chat')`。
100. 性能：头像懒加载、横幅 preload 当前+左右各一张，15 张全 preload 可去掉。
