# OpenCanvas AI 功能路线图 / Backlog

> 当前已有：多模型网关（国内外 + 前台 BYOK）、流式对话、PPT 生成/编辑/导出 PPTX、
> AI 绘图、数据持久化（SQLite）、历史管理（搜索/筛选/置顶/重命名/归档/批量）、场景模板、落地页。
> 下面按优先级列出可继续增加的内容。优先级：P0 必做 / P1 高价值 / P2 中长期。

---

## 一、核心创作能力（补齐对标 HIX/Genspark）

### 1. 深度研究 Deep Research（P0，最该做）
- 联网搜索：接 Tavily / Exa（海外）、博查/秘塔（国内）
- Agent 多轮检索：拆问题 → 并⾏搜索 → Jina Reader 读网页 → 去重打分 → 补搜
- 输出**带引用角标**的研究报告（Artifact 文档）
- 报告**一键转 PPT**（打通研究→演示招牌链路）
- 异步任务 + WebSocket/SSE 进度（"正在阅读第 N 个来源"）
- 预估工作量：中（复用现有网关 + 队列思路）

### 2. 富文本文档编辑器（P0）
- TipTap/BlockNote：对话产物可在画布直接编辑
- AI 操作：续写、改写、扩写、缩写、翻译、换语气、纠错
- 文档自动保存、导出 Word/PDF/Markdown
- 文档库（独立 /docs 列表页）

### 3. AI 视频生成（P1）
- 文生视频/图生视频：接 Seedance、Kling、可灵（国内）、Veo（海外）
- 分镜脚本 → 逐镜生成 → 合并 → 视频画廊（复用图像工作台 UI）
- 异步任务队列（分钟级），进度推送
- 配音/字幕（TTS）

### 4. Agent「一句话出整套素材包」（P1，HIX 主打）
- 多节点工作流编排（LangGraph 风格）：
  新品发布 = 研究 → 文案×N → 配图×N → 视频脚本 → PPT
- 节点产物共享上下文（品牌语调 + 研究结论）
- 预置包：产品发布套件、社媒 campaign、网络研讨会、儿童绘本、电商详情页

### 5. 代码生成与预览（P1）
- 生成 HTML/React 单页，iframe 沙箱实时预览
- 落地页/原型/小工具一键生成，截图/部署

### 6. PPT 能力增强（P1）
- 「配图位」自动调绘图模型**填真实图片**
- 更多版式（时间轴、对比、流程图、团队、引用）
- AI 单页重写/换风格/自动排版
- 演讲者备注、导出 PDF、主题市场、模板库
- 大纲先行（先出大纲可编辑，再生成成稿）

### 7. 图像能力增强（P2）
- 图生图、局部重绘、扩图、风格参考图
- 背景移除、智能扩图、Logo/海报/社媒尺寸模板
- 组图（同一主体多视角/多场景）
- 接 FLUX、Seedream、可灵图像等更多模型

### 8. 品牌中心 Brand Kit（P2）
- 上传 Logo、色板、字体、品牌语调描述
- 所有 PPT/图/文案自动套用，保持风格一致

### 9. 知识库 RAG（P2）
- 上传 PDF/Word/网页 → 向量化 → 对话/写作时引用自有资料

## 二、账户与商业化

### 10. 用户体系（P0 商业化前置）
- 海外：Clerk/Auth0（邮箱/Google）
- 国内：手机号验证码 + 微信登录
- 数据按用户隔离（现在是单用户本地版）

### 11. 积分与支付（P1）
- 积分账本真实落库（现在是纯函数）：预扣、结算、流水
- 订阅套餐 + 充值包
- 海外 Stripe；国内微信支付/支付宝（聚合）
- 用量/账单页面

### 12. 团队与协作（P2）
- 团队工作区、成员、共享品牌库/模板
- 产物链接分享（只读页）、评论

### 13. API 开放平台（P2）
- 对外 OpenAI 兼容接口，按 token 计费
- 开发者文档、API Key 管理

## 三、基础设施

### 14. 生产化存储与队列（P1）
- SQLite → PostgreSQL（schema 已备好）
- Redis + BullMQ：研究/视频/批量任务异步化
- 文件存 Cloudflare R2 / S3（图片、视频、导出文件）

### 15. 模型网关增强（P1）
- 失败自动降级/重试/超时（Claude 挂 → 切 GPT）
- 多 Key 轮询、限流、按真实 token 精确计费
- 接入更多模型：Gemini、Kling、FLUX、MiniMax、智谱等
- 网关成本看板（毛利核算）

### 16. 可观测性（P2）
- 任务日志、错误追踪（Sentry）、埋点统计
