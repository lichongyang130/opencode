# OpenCanvas 改进 / 修复建议 100 条

> 结合当前代码库与产品现状整理，按模块分组，标注（已做）的为已落地项。

## 一、首页与新手引导（1-12）
1. 首页只保留「标题 + 输入框 + 发送」，其余能力下沉，降低认知负担（已做）。
2. 首次进入增加 3 步新手引导：输入 → 回车 → 看右侧产物。
3. 占位文案用真实可执行的例子，示例点击直接填充输入框（已做）。
4. 示例做成小胶囊/轮播占位，避免大卡片堆砌（已做）。
5. 首页显示「上次任务」快捷恢复入口。
6. 空状态提供「随机灵感」按钮，解决不知道写什么。
7. 首页加载做骨架屏，避免白屏。
8. 标题用一句价值主张，而非功能罗列。
9. 模式选择不放首页，用输入后智能识别或由示例带出（已做）。
10. 增加深色/浅色主题切换并记住偏好。
11. 首页输入框支持拖拽文件/图片直接附加。
12. 提供「语音输入」按钮，降低输入门槛。

## 二、输入与交互（13-24）

20. 长任务显示阶段提示（思考 / 生成 / 渲染）。
