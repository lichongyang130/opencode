OpenCanvas 首页 · 5 版效果图

五个差异化的设计方向，供选型参考 —— 均为概念稿，最终以真实中文界面为准

V1 · 单框直达

极简 One-Box

打开就是一个大输入框，无侧栏无层级。学习成本最低，最贴近大众 AI 产品（ChatGPT / Claude）的心智；由 AI 自动判断用对话 / 文档 / PPT 哪种方式完成。

适用：重视「零门槛上手」 · 冷启动 / 新手友好

V2 · 全能工作台

三栏 Workspace 首页

保留现有产品形态：左侧能力图标轨 + 会话历史 + 居中对话与分体输入舱，暖米色纸张质感。重度用户最顺手，体现「一站式 AI 工作空间」的产品定位。

适用：功能完整展示 · 老用户 / 深度办公场景

V3 · 深色高能

Dark Pro 氛围款

深炭黑底 + 橙紫极光渐变 + 玻璃拟态，中央一句大字「把想法变成作品」。视觉冲击强，突出「创造感」与高级感，适合发布会 / 极客向投放。

适用：品牌调性 / 营销落地页 / 深色模式主打

V4 · 模板货架

Template Gallery 导购式

以「模板 / 场景卡片」为骨架：顶部导航 + 橙色 Banner + 搜索框 + 模板瀑布流。用户不是先打字而是先「挑一个要干的活」，对不知道 AI 能做什么的人非常有效。

适用：模板中心已有丰富内容 · 导购转化导向

V5 · 亲切对话

Friendly 聊天式

奶油底色 + 超大圆角 + 表情化问候（“早上好！今天想干点啥？”），把首页做成一张「有人情味的对话卡」，右侧示例气泡示范 AI 能做什么，用户跟着点就行。

适用：消费级 / 长辈与小白用户 / 降低“AI 很专业”的距离感
